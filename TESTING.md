# Тестирование без Prometheus

Этот проект **не требует запущенного Prometheus сервера**. Формат Prometheus используется только для структуры данных, совместимой с `viewer.html`.

## Быстрое тестирование

### 1. Базовый тест (рекомендуется)

```bash
# Запустить автоматический тест
python3 test_metrics.py
```

Этот скрипт проверит:
- ✅ Импорт всех модулей
- ✅ Анализ проекта
- ✅ Генерацию файлов метрик
- ✅ Корректность формата Prometheus
- ✅ Наличие всех необходимых метрик

### 2. Тест основной команды

```bash
# Анализ с генерацией treemap метрик
python3 main.py . --dirs src/ --treemap --output metrics
```

Это создаст:
- `metrics.md` - архитектурный анализ в Markdown
- `metrics.json` - данные анализа в JSON
- `metrics_treemap.prom` - метрики для визуализации

### 3. Альтернативный способ (через example_usage.py)

```bash
# Анализ всего проекта (без фильтрации по директориям)
python3 example_usage.py
```

Создаст `python_metrics.prom` с метриками всего проекта.

## Проверка результатов

### Проверка файлов

```bash
# Проверить наличие файлов
ls -lh metrics*.prom metrics*.md metrics*.json

# Посмотреть содержимое метрик (первые строки)
head -20 metrics_treemap.prom
```

### Визуализация в браузере

1. **Откройте `viewer.html`** в браузере
2. **Перетащите файл `.prom`** в окно браузера
3. Или используйте URL параметр:
   ```
   file:///путь/к/viewer.html?data=/путь/к/metrics_treemap.prom
   ```

### Проверка формата Prometheus

Файл `.prom` должен содержать:
- Комментарии `# HELP` и `# TYPE` для каждой метрики
- Метрики в формате: `metric_name{labels} value`
- Метки: `ns`, `name`, `line`

Пример корректной строки:
```
python_expressions{ns="src.calculator",name="add",line="12"} 45
```

## Что проверяется

### Метрики компилятора (compiler)
- ✅ `python_expressions` - количество узлов AST
- ✅ `python_max_depth` - максимальная глубина вложенности
- ✅ `python_complexity` - цикломатическая сложность
- ✅ `python_unused` - флаг неиспользуемых функций (1 = не используется)

### Метрики classloader
- ⚠️ `python_bytecode_size` - пока не реализовано (остается для совместимости)

## Устранение проблем

### Ошибка: "Directory not found: src/"
Создайте тестовую директорию:
```bash
mkdir -p src
# Добавьте тестовые Python файлы в src/
```

### Ошибка: "Could not generate treemap metrics"
Проверьте, что модули `core.py`, `metrics.py`, `prometheus.py` находятся в той же директории.

### Файлы не создаются
Проверьте права на запись в текущую директорию:
```bash
ls -ld .
```

## Примеры тестовых данных

В проекте уже создана тестовая структура `src/` с примерами:
- `src/calculator.py` - класс Calculator с методами разной сложности

- `src/__init__.py` - инициализация пакета
